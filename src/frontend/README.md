# SciQuiz TN - Tamil Nadu Science Quiz Application

A gamified science quiz application for Tamil Nadu students (Class 6-10) built on the Internet Computer platform.

## Features

- **Multi-Level Quizzes**: Separate question sets for Class 6, 7, 8, 9, and 10
- **Gamified UI**: Modern, engaging interface with animations and visual feedback
- **Timed Questions**: 30-second countdown timer for each question
- **Instant Feedback**: Immediate visual feedback on answer selection
- **Progress Tracking**: Real-time score tracking and performance metrics
- **Review Mode**: Comprehensive review of all answers after quiz completion
- **Background Music**: Optional background music with volume controls
- **Internet Identity**: Secure authentication using Internet Computer's Internet Identity
- **Responsive Design**: Works seamlessly on desktop and mobile devices
